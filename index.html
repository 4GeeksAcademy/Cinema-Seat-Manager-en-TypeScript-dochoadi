Cinema Seat Manager · Versión 1 (consola)

Esta versión es un programa de línea de comandos: no tiene interfaz web. Se usa desde la terminal: 

npm install
npm run test   # termina con "Pruebas superadas: 20/20"

Muestra la sala de 8 × 10, las reservas, el conteo de asientos y la búsqueda de dos asientos juntos en cinco escenarios de prueba.
